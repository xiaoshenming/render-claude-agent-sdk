# Manim 统一 Quality Agent 完整交接说明

## 1. 交付物是什么

这是当前冻结的统一 Agent MVP，不是旧的 LangGraph、mini-swe-agent、Pi
实验，也不是只包含接口定义的空壳。

完整执行链如下：

```text
可渲染 candidate.py
  -> 只提取 class Solution(BaseConfigScene)
  -> 数学/几何 Reviewer 子 Agent
  -> 动画生命周期 Reviewer 子 Agent
  -> 父 Quality Agent 合并问题
  -> 受控块级 Patch
  -> 真实 Manim 渲染 + ffprobe
  -> BBox 快照 + 重叠检测
  -> 必要时继续受控 Patch（预算按 R0 基线 blocking 数定为 5..7 次）
  -> 独立重新渲染 + 独立重叠复检
  -> PROPOSED 或 HOLD
  -> 完整审计目录
```

两个 Reviewer、父 Agent、七个工具、Revision 管理、Manim 运行适配、
BBox 探针、重叠 detector 和外层验收门禁都包含在 `agent/` 中。

## 3. 必须准备的外部环境

交付包自身完整，但真实 Manim 视频运行仍需要以下机器环境：

1. Windows 10/11 或兼容的 Linux 环境。
2. Python 3.11，用于运行 Agent。
3. 一个能够运行目标 `candidate.py` 的 Python/Manim 解释器。
4. FFmpeg 和 ffprobe。
5. LaTeX 与目标代码使用的字体。
6. Anthropic Messages 兼容网关的 URL、Key 和模型名。

“Agent Python”和“Manim Python”允许是同一个解释器，也允许分开。目标代码若
依赖项目私有的 `base`、TTS 或配置模块，需要通过
`--runtime-python-path` 提供。Agent 看不到这些目录，只有渲染子进程使用。

## 4. 第一次运行

在交接包根目录打开 PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\handoff\scripts\setup_agent.ps1
```

Windows 请将包解压到较短路径，例如
`D:\ManimQualityAgent_20260726`，避免虚拟环境安装触发旧版长路径限制。

然后只在当前 PowerShell 设置密钥：

```powershell
$env:ANTHROPIC_BASE_URL = "https://your-anthropic-compatible-endpoint"
$env:ANTHROPIC_AUTH_TOKEN = "<your-runtime-secret>"
$env:QUALITY_MODEL = "your-model"
```

运行预检：

```powershell
.\handoff\scripts\preflight.ps1 `
  -ManimPython "D:\runtime\python.exe" `
  -RuntimePythonPath "D:\runtime\runtime_stubs"
```

预检通过后，按 `01_完整运行手册.md` 跑单题或 17 题。

## 5. 结果口径

- `PROPOSED`：通过真实渲染、ffprobe、独立布局复检，且无阻塞重叠。
- `HOLD`：未满足门禁，系统回滚到 R0，不应交付候选。
- `FAILED`：Agent、工具、运行时或预算异常导致中断。此时会写失败归档
  （`logs/failure.json`、`output/last_candidate.<Rn>.py`，可能还有
  `output/best_render_passed.<Rn>.py`），见 `02_输入输出与日志.md` §3.1。
  `best_render_passed` 是证据不是交付物。

`PROPOSED` 当前不是独立数学正确性证明。两个 Reviewer 会审查并修复逻辑，
但外层门禁目前独立验证的是可渲染性和布局事实；生产接入仍建议增加独立 Final
Logic Verifier 的影子评估。
