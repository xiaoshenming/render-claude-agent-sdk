# 离线压缩包完整搭建与使用流程

## 1. 先分清包内两套代码

压缩包根目录是独立的 `render-claude-agent-sdk` 仓库代码，用于开发、测试和独立运行质量平台；`vendor/source_archives/server3_render_logic_overlap_runtime_20260804.tar.gz` 则是 server3 的 8081 任务链最终调用的 Render 运行态冻结包。

两者不要混为一个版本：

| 范围 | 用途 | Claude Agent SDK |
|---|---|---:|
| 压缩包根目录 | 独立质量平台开发与复现实验 | 0.2.128 |
| server3 冻结归档 | 8081 → 8889 → 8002 的真实运行代码 | 0.2.116 |

要研究线上真实行为，先看冻结归档；要继续开发通用平台，使用压缩包根目录。

## 2. 解压并验证

将外层 ZIP 解压到短路径，进入根目录：

```bash
python handoff/server3-logic-overlap-20260804/verify_snapshot.py
```

预期输出：

```text
OK archive_sha=1ee04445f1ac88a2d894f175088c3ef9a1cce87f1eaf6a0278854d3e5da01473
OK core_files=947
OK no_dotenv_in_archive=true
```

然后把 server3 冻结包解压到独立目录：

```bash
mkdir -p runtime_snapshot
tar -xzf vendor/source_archives/server3_render_logic_overlap_runtime_20260804.tar.gz \
  -C runtime_snapshot
```

不要覆盖压缩包根目录，也不要直接覆盖正在运行的 MathPi Render。

## 4. 独立 SDK 平台环境

基础要求：

- Python 3.11；不要使用 3.12。
- `uv` 或兼容的 Python 虚拟环境工具。
- 真实渲染需要 Manim、FFmpeg/ffprobe、LaTeX、Cairo/Pango 和对应字体。
- 一个 Anthropic Messages 兼容网关、Key 和模型名。

Linux/macOS：

```bash
uv sync --extra dev
uv run python -m pytest -q
uv run python scripts/check_engineering_standards.py
```

Windows PowerShell：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\handoff\scripts\setup_agent.ps1
```

只把密钥放在当前进程环境：

```bash
export ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
export ANTHROPIC_AUTH_TOKEN="<由接收方安全提供>"
export QUALITY_MODEL="deepseek-v4-flash"
```

不要把真实 Key 写入 `.env`、脚本、Markdown、JSON、日志或 Git。

## 6. Server3 冻结运行时代码环境

冻结运行时的 Python 依赖锁在：

`runtime_snapshot/requirements.txt`

核心版本包括：

- `claude-agent-sdk==0.2.116`
- `manim==0.19.0`
- `manim-voiceover==0.3.7`
- `aio-pika==9.5.7`
- `fastapi==0.121.0`
- `pydantic==2.12.4`

创建审计环境可使用：

```bash
python3.11 -m venv .venv-server3-snapshot
source .venv-server3-snapshot/bin/activate
python -m pip install --upgrade pip
python -m pip install -r runtime_snapshot/requirements.txt
```

但安装 Python 包不代表能够完整渲染。真实运行还依赖 MathPi 的 Manim Docker、字体、LaTeX、FFmpeg、`custom_services`、基础 Scene/Header、RabbitMQ、Redis、数据库和 COS 配置。这些环境数据不属于 Agent 源码包，也不能把 server3 密钥打进交付物。

## 7. V3 Harness 的关键环境变量

server3 实际模型配置：

```bash
export MANIM_QUALITY_MODEL="deepseek-v4-flash"
export MANIM_QUALITY_ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
export MANIM_QUALITY_ANTHROPIC_API_KEY="<由接收方安全提供>"
export MANIM_QUALITY_V3_ROOT="$PWD/runtime_snapshot/manim_quality_platform/v3"
```

V3 runner 会把 provider 配置映射为 `ANTHROPIC_BASE_URL`、`ANTHROPIC_AUTH_TOKEN`、`ANTHROPIC_API_KEY` 和 `QUALITY_MODEL`，然后调用：

```text
manim_quality_platform/v3/scripts/run_existing_code_e2e.py
```

不要跳过 `MANIM_QUALITY_V3_ROOT`；缺少这一级目录时，`app/` 虽然完整，Agent 仍无法真正启动。

## 8. 接入 MathPi Render

线上真实链路是：

```text
管理后台 8081
→ Nginx /api/
→ mathpi-api 8889
→ RabbitMQ
→ mathpi-render 8002
→ minimal_archive
→ pre_archive
→ V3 Logic + Overlap/Layout Agent
```

冻结包用于对比、移植或恢复，不应直接覆盖目标服务器。接入时需要：

1. 将冻结包与目标 Render 逐文件比较。
2. 保留目标环境 `.env`、venv、证书、媒体、缓存和任务数据。
3. 核对 V3 Harness 目录与 `MANIM_QUALITY_V3_ROOT`。
4. 核对 `custom_services`、Manim Header 和容器卷。
5. 先备份所有待覆盖文件。
6. 先运行编译、单测和单题离线 canary。
7. 得到授权后才允许同步代码或重启服务。
8. 上线后用真实新任务核验质量事件、Token、视频和回滚条件。

## 9. 最小 canary 验收

至少准备一个已知可渲染的横屏静音几何任务，记录：

- 输入题目、期望解答与 candidate.py SHA。
- 模型、SDK、Prompt/Schema、工具和预算版本。
- Logic Review、Logic Repair、Overlap/Layout 的状态、Token 和耗时。
- 初始与最终 blocking issue 数。
- 每轮 revision 和源码 SHA。
- 最终视频路径、ffprobe、分辨率、时长和 HTTP Range 206。

出现 Agent 异常时应保留原始可播放候选和完整证据。质量问题默认走输入合同、Prompt、工具和修复路线，不能擅自新增质量硬拦截。

## 10. 常见误区

- 只安装根目录依赖，不能复刻 server3 的 0.2.116 运行时。
- 只复制 `app/` 而漏掉 `manim_quality_platform/v3/`，V3 runner 无法启动。
- 数据库 SUCCESS 不等于 COS 视频可播放。
- Agent 报告 ACCEPT 不等于人工确认所有视觉问题消失。
- 8081 是管理后台入口，Agent 实际运行在 8002 Render 服务。
- 没有明确授权时，不要部署、重启、推送配置或覆盖服务器。
