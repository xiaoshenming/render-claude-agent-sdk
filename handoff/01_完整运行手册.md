# 完整运行手册

## A. 环境安装

进入交接包根目录：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\handoff\scripts\setup_agent.ps1
```

脚本执行：

1. 检查 Python 3.11；
2. 创建 `agent\.venv`；
3. 安装项目声明的 Agent 和验证依赖（Claude Agent SDK 固定为 0.2.128）；
4. materialize 冻结的重叠运行时；
5. 验证当前线路实际使用的重叠归档 Hash、导入和集成行为；
6. 执行 Agent/operator 聚焦测试和工程规范检查。

不会安装 Manim、LaTeX、字体或项目私有运行库，因为这些必须与生产渲染环境
保持一致。

仓库另保留历史 `logic_self_audit_baseline` 以追溯旧实验，其全量 provenance
校验存在已知旧 Hash 不一致；它不参与当前统一 Agent 入口，安装脚本不会用这份
历史快照给当前运行时做真假判断。

## B. 运行时配置

密钥只放进当前进程环境：

```powershell
$env:ANTHROPIC_BASE_URL = "https://gateway.example"
$env:ANTHROPIC_AUTH_TOKEN = "<secret>"
$env:QUALITY_MODEL = "model-name"
```

兼容网关若只读取 `ANTHROPIC_API_KEY`，可改用：

```powershell
$env:ANTHROPIC_API_KEY = "<secret>"
```

不要把真实 Key 写入 `.env`、命令脚本、JSON、Markdown、Git 或运行包。

## C. 运行前预检

```powershell
.\handoff\scripts\preflight.ps1 `
  -ManimPython "D:\runtime\python.exe" `
  -RuntimePythonPath "D:\runtime\runtime_stubs"
```

如果目标代码不需要私有模块，可省略 `-RuntimePythonPath`。如果有多个导入根，
传数组：

```powershell
-RuntimePythonPath @("D:\runtime\stubs", "D:\runtime\project")
```

预检检查：

- 包 Hash；
- Python 版本；
- Agent 可导入；
- Claude Agent SDK 可导入；
- 重叠 vendor 已 materialize 且 Hash 正确；
- Manim、ffmpeg、ffprobe 是否可用；
- 网关 URL、认证变量和模型名是否存在；
- 17 题复现输入是否完整。

## D. 跑一个真实任务

```powershell
.\handoff\scripts\run_one.ps1 `
  -Candidate "D:\task\candidate.py" `
  -Workspace "D:\task" `
  -Output "D:\runs\quality-001" `
  -ManimPython "D:\runtime\python.exe" `
  -RuntimePythonPath @("D:\runtime\runtime_stubs") `
  -AssetsDir "D:\task\assets"
```

如源码顶部没有题目和解题过程，额外传：

```powershell
-Problem "D:\task\problem.txt"
```

CLI 默认预算：

```text
max turns:          24
max tool calls:     40
candidate revisions: R1 起动态，Patch 预算按 R0 基线 blocking 数确定
                     blocking <= 2 -> 5 个 Patch（最多到 R5）
                     blocking 3..8 -> 6 个 Patch（最多到 R6）
                     blocking > 8  -> 7 个 Patch（最多到 R7）
```

Patch 预算由 Harness 在会话开始前根据 R0 的独立布局复检结果一次性确定，会话中
只能抬高不能下调。`validate_revision` 与 Patch 预算等值，`inspect_layout` 多一
次（用于提交前对最终 revision 复检）。

另有 30 分钟（`max_elapsed_ms = 1_800_000`）的 Agent 硬时限，但它只计模型推理
和协议时间：外部渲染与 BBox 探针的墙钟被剔除，工具执行期间会话 deadline 挂起。
所以一道题的真实墙钟可以远超 30 分钟而不触发超时，批处理的 `--case-timeout`
才是每题的墙钟上限。

`run_one.ps1` 的 `-MaxTurns` / `-MaxToolCalls` 参数仍保留旧默认值（16 / 18），
需要按当前口径跑时请显式传 `-MaxTurns 24 -MaxToolCalls 40`。

## E. 跑包内 17 题

当前请直接调用批处理脚本：

```powershell
.\.venv\Scripts\python.exe scripts\run_unified_quality_batch.py `
  --package .\reproduction_inputs\MathPi_17 `
  --output "D:\runs\unified-agent-17" `
  --repo (Get-Location) `
  --model $env:QUALITY_MODEL `
  --manim-python "D:\runtime\python.exe" `
  --runtime-python-path "D:\runtime\runtime_stubs"
```

> `handoff\scripts\run_17.ps1` 目前仍在传已被移除的 `--concurrency`，并写死
> `--max-turns 16 --max-tool-calls 18`，直接运行会被 argparse 拒绝。修好之前请
> 用上面的直调命令。

批处理默认值：

```text
--agent-concurrency   20    # 同时在跑的 Agent 会话数
--render-concurrency  10    # 跨进程渲染槽位上限
--case-timeout        3600  # 每题墙钟上限（秒）
--case-grace          120   # 超时后 SIGTERM 到 SIGKILL 的宽限（秒）
--max-turns           24
--max-tool-calls      40
```

Agent 并发和渲染并发现在是**两个独立维度**。Agent 会话大部分时间在等外部工具，
所以可以开到 20；真正抢 CPU、内存和临时文件的是 Manim/LaTeX，由
`--render-concurrency` 通过 `<output>\_render_slots` 下的跨进程信号量单独限流。
调并发时只动 `--render-concurrency` 来匹配机器规格，不要为了压渲染负载把
`--agent-concurrency` 一起压低。

每题超时后先发 SIGTERM，留 `--case-grace` 秒让 CLI 落盘失败证据（见
`02_输入输出与日志.md` 的失败归档），宽限期过了才 SIGKILL。所以超时的题通常仍
有 `logs/failure.json` 和 `output/last_candidate.<Rn>.py` 可查。

每次使用新输出目录。批处理会保留每题完整审计证据，并生成：

```text
<output>\batch_summary.json
<output>\_batch_logs\<case>.stdout.log
<output>\_batch_logs\<case>.stderr.log
```

## F. 服务或平台接入

生产接入的稳定入口是：

```python
from manim_quality.operator.harness import QualityHarness
```

命令行入口是：

```text
python -m manim_quality.operator
```

外部平台只负责提交：

```text
candidate.py
workspace
problem（可选）
assets
Manim runtime 参数
run_id
artifact_root
```

外部平台不得伪造 `PROPOSED`、直接写 revision、绕过外层门禁或只根据 Agent
文字声明放行。正式生产可以在 CLI 外包一层队列 Worker，但不要重新手搓
Reviewer/Coder/Verifier 路由。

## G. 环境版本记录

每次实验必须记录：

- Agent 源 commit 和 `uv.lock` Hash；
- Python、Claude Agent SDK、Manim、FFmpeg 版本；
- 网关类型和模型名，不记录 Key；
- 输入包 Hash；
- turns、tool calls、并发和超时；
- 每题状态、Tokens、耗时、revision、渲染次数和失败原因。
