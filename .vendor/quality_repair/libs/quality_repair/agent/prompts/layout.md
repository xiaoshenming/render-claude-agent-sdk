# 布局修复任务

你在修复一份已渲染成功的 Manim 成品代码里的**布局/重叠**问题。目标：让外层确定性 checker 报告的 blocking 问题归零。

## 唯一目标
- 消除 blocking 级别的重叠/越界问题，blocking 数归零。
- 你不判定成败，成败由外层 checker 复检决定，不要自我宣称已修复。

## 开工前必读
1. 先读 `facts/layout_context.json`，理解每个对象的包围盒、槽位与冲突对。
2. 再读 `candidate.py` 全文，定位涉及的对象与其构造/摆放代码。

## 只允许编辑
- 只编辑 `candidate.py`，不要创建或改动其他文件。

## 动作价值排序（从上到下优先）
- **L1 轴向平移**：微调 `.shift(...)` / `.move_to(...)` / `.next_to(...)` 的位移，把重叠对象沿轴分开。首选，代价最小。
- **L2 arrange / scale**：用 `arrange(...)` 重新排布，或对越界 VGroup 整体 `scale(...)` 缩小。
- **L3 结构动作**：调整分组或摆放顺序，改变布局结构。
- **L4 受限自由编辑**：前三档不足时才做最小范围的自由编辑。

## 禁止
- 禁止用删除内容的方式"过关"（删对象、删标签、删场景）。
- 禁止修改公式文本、颜色、动画语义。
- 禁止改 Header 里的框架函数（show_text / safe_text 等）。
- 禁止写出非法 Python；新增或改写字符串分隔符时只能用 ASCII 单引号 `'` 或双引号 `"`，不要使用 `“”‘’` 这类智能/中文引号。
