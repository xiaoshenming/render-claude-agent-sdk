分别是 BC ， CD 上的点 (1) 若 ∠EAF=1/2 ∠BAD ，求证

```python
# PROBLEM_TEXT: 四边形 ABCD 中， AB=AD ， ∠B+∠D=180° ， E ， F 分别是 BC ， CD 上的点 (1) 若 ∠EAF=1/2 ∠BAD ，求证: BE+FD=EF (2) 若 BE+FD=EF ，求证: ∠EAF=1/2 ∠BAD。
# FIGURE_FACTS: 四边形ABCD, AB=AD, ∠B+∠D=180, E在BC上, F在CD上, 连接AE, AF, EF

from manim import *

class GeometryScene(Scene):
    def construct(self):
        # 定义顶点坐标
        A = np.array([-1.8, 1.7, 0])
        B = np.array([-2.3, -1.8, 0])
        C = np.array([2.3, -1.8, 0])
        D = np.array([1.7, 1.8, 0])
        E = np.array([-1.0, -1.8, 0])
        F = np.array([1.94, 0.36, 0])
        
        # 创建四边形的外边框线段
        ab = Line(A, B, stroke_width=3, color=WHITE)
        bc = Line(B, C, stroke_width=3, color=WHITE)
        cd = Line(C, D, stroke_width=3, color=WHITE)
        da = Line(D, A, stroke_width=3, color=WHITE)
        
        # 创建内部连接线段
        ae = Line(A, E, stroke_width=3, color=WHITE)
        af = Line(A, F, stroke_width=3, color=WHITE)
        ef = Line(E, F, stroke_width=3, color=WHITE)
        
        # 创建顶点标签
        label_A = MathTex("A").next_to(A, UP + LEFT, buff=0.15)
        label_B = MathTex("B").next_to(B, DOWN + LEFT, buff=0.15)
        label_C = MathTex("C").next_to(C, DOWN + RIGHT, buff=0.15)
        label_D = MathTex("D").next_to(D, UP + RIGHT, buff=0.15)
        label_E = MathTex("E").next_to(E, DOWN, buff=0.15)
        label_F = MathTex("F").next_to(F, RIGHT, buff=0.15)
        
        # 组合所有几何元素并添加到场景中
        geometry = VGroup(
            ab, bc, cd, da, ae, af, ef,
            label_A, label_B, label_C, label_D, label_E, label_F
        )
        
        self.add(geometry)
```

【读题展示阶段】
先自然读题，不进入证明。题目给出：四边形 ABCD 中， AB=AD ， ∠B+∠D=180° ， E ， F 分别是 BC ， CD 上的点 (1) 若 ∠EAF=1/2 ∠BAD ，求证: BE+FD=EF (2) 若 BE+FD=EF ，求证: ∠EAF=1/2 ∠BAD。读到 AB=AD 时高亮 AB、AD；读到 FD=EF 时高亮 FD、EF。最后读出求证：BE+FD=EF (2) 若 BE+FD=EF ，求证: ∠EAF=1/2 ∠BAD，只高亮结论中的关键线段或角。
【思路切入阶段】
本题最终要证明给出的线段或角关系，直接在四边形里推不清楚。先利用 AB=AD 和 ∠B+∠D=180° 捕捉一组对称式的角关系，再把 ∠EAF 与 ∠BAD 的半角条件转成两边夹角；最后围绕 △ABE 与 △ADF 或相关小三角形建立全等，把对应线段和角转出来。
【满分答案阶段：必须完整展示的官方解题步骤】
(1)证明：
延长 CB 到点 G ，使 BG=DF ，连接 AG 。
∵ ∠ABC + ∠D = 180° ， ∠ABC + ∠ABG = 180° ，
∴ ∠ABG = ∠D 。
在 △ABG 和 △ADF 中：
\begin{cases}AB=AD \\∠ABG=∠D \\BG=DF\end{cases} ∴ △ABG ≌ △ADF \ (SAS) ，
∴ AG=AF ， ∠BAG = ∠DAF 。
∵ ∠EAF = \frac{1}{2}∠BAD ，
∴ ∠BAE + ∠DAF = \frac{1}{2}∠BAD ，
∴ ∠BAE + ∠BAG = \frac{1}{2}∠BAD ，即 ∠GAE = \frac{1}{2}∠BAD ，
∴ ∠GAE = ∠EAF 。
在 △GAE 和 △FAE 中：
\begin{cases}AG=AF \\∠GAE=∠EAF \\AE=AE\end{cases} ∴ △GAE ≌ △FAE \ (SAS) ，
∴ GE=EF 。
∵ GE = BE + BG = BE + DF ，
∴ BE+FD=EF 。

(2)证明：
延长 CB 到点 G ，使 BG=DF ，连接 AG 。
同理可证 △ABG ≌ △ADF \ (SAS) ，
∴ AG=AF ， ∠BAG = ∠DAF 。
∵ EF=BE+FD ， BG=DF ，
∴ EF = BE + BG = GE 。
在 △GAE 和 △FAE 中：
\begin{cases}AG=AF \\GE=EF \\AE=AE\end{cases} ∴ △GAE ≌ △FAE \ (SSS) ，
∴ ∠GAE = ∠EAF 。
∵ ∠GAE = ∠BAE + ∠BAG = ∠BAE + ∠DAF ，
∴ ∠EAF = ∠BAE + ∠DAF ，
∴ ∠BAD = ∠BAE + ∠EAF + ∠DAF = 2∠EAF ，
即 ∠EAF = \frac{1}{2}∠BAD 。

【结论收束阶段】
最后收束结论：∴ ∠BAD = ∠BAE + ∠EAF + ∠DAF = 2∠EAF ， 即 ∠EAF = \frac{1}{2}∠BAD 。

本题可迁移的方法是“先全等造条件，再用对应关系证目标”。证明时要写清三角形、条件和判定依据。
