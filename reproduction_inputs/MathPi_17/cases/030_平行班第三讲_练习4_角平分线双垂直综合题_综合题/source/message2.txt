# PROBLEM_TEXT: 如图，BD = CD, ∠ABD = ∠ACD = 90°, 点 E, F 分别在 AB, AC 上，若 ED 平分 ∠BEF. (1) 求证：FD 平分 ∠EFC; (2) 求证：EF = BE + CF. (3) 若 EF = 4, AF = 6, AE = 5, 则 BE = _______.
# FIGURE_FACTS: BD = CD, ∠ABD = ∠ACD = 90°, E is on AB, F is on AC, ED bisects ∠BEF

from manim import *

class GeometryScene(Scene):
    def construct(self):
        # Define key points
        A = np.array([0, 3.25, 0])
        D = np.array([0, -2.08, 0])
        B = np.array([-2.6, 0, 0])
        C = np.array([2.6, 0, 0])
        
        # E is on AB, F is on AC
        E = A + 0.65 * (B - A)
        F = A + 0.75 * (C - A)

        # Draw lines
        line_AB = Line(A, B, stroke_width=2, color=WHITE)
        line_AC = Line(A, C, stroke_width=2, color=WHITE)
        line_BD = Line(B, D, stroke_width=2, color=WHITE)
        line_CD = Line(C, D, stroke_width=2, color=WHITE)
        line_ED = Line(E, D, stroke_width=2, color=WHITE)
        line_FD = Line(F, D, stroke_width=2, color=WHITE)
        line_EF = Line(E, F, stroke_width=2, color=WHITE)

        # Right angle mark at B
        u1 = (A - B) / np.linalg.norm(A - B)
        u2 = (D - B) / np.linalg.norm(D - B)
        s = 0.25
        p1 = B + s * u1
        p2 = B + s * u1 + s * u2
        p3 = B + s * u2
        right_angle_B = VMobject(color=WHITE, stroke_width=1.5)
        right_angle_B.set_points_as_corners([p1, p2, p3])

        # Right angle mark at C
        v1 = (A - C) / np.linalg.norm(A - C)
        v2 = (D - C) / np.linalg.norm(D - C)
        q1 = C + s * v1
        q2 = C + s * v1 + s * v2
        q3 = C + s * v2
        right_angle_C = VMobject(color=WHITE, stroke_width=1.5)
        right_angle_C.set_points_as_corners([q1, q2, q3])

        # Labels
        label_A = MathTex("A").next_to(A, UP, buff=0.15)
        label_B = MathTex("B").next_to(B, LEFT, buff=0.15)
        label_C = MathTex("C").next_to(C, RIGHT, buff=0.15)
        label_D = MathTex("D").next_to(D, DOWN, buff=0.15)
        label_E = MathTex("E").next_to(E, UL, buff=0.1)
        label_F = MathTex("F").next_to(F, UR, buff=0.1)

        # Group all elements
        geometry_group = VGroup(
            line_AB, line_AC, line_BD, line_CD, line_ED, line_FD, line_EF,
            right_angle_B, right_angle_C,
            label_A, label_B, label_C, label_D, label_E, label_F
        )

        # Add to scene
        self.add(geometry_group)

【老师原始解题步骤】
以下内容只保真数学内容、证明顺序和结论；其中旧式 LaTeX 包装不得直接复制为显示代码。
题目
如图，BD=CD，∠ABD=∠ACD=90°，ED平分∠BEF。 (1) 求证：FD平分∠EFC； (2) 求证：EF=BE+CF； (3) 若EF=4，AF=6，AE=5，求BE的长。
(1) 求证：FD平分∠EFC
模块1 答案解析
作DG⊥EF，利用角平分线性质和等量代换，证明D到EF与D到FC的距离相等，从而证得FD平分∠EFC。
模块2 解析过程
审题与切入
要证角平分线，根据角平分线的判定定理，只需证明点D到∠EFC两边的距离相等。题目给出ED平分角和两个直角，因此过D作EF的垂线，作为桥梁联系两条距离。
解题思路与核心定理
角平分线的性质：角平分线上的点到角两边的距离相等； 角平分线的判定：角的内部到角两边距离相等的点，在角的平分线上。 核心辅助线：过D作DG⊥EF于G。
具体推导过程
第一步：作辅助线 过点D作DG⊥EF于点G。
第二步：由角平分线性质得DB=DG ∵ ∠ABD=90°，∴ DB⊥AB。 ∵ ED平分∠BEF，DB⊥AB，DG⊥EF， ∴ DB = DG（角平分线上的点到角两边的距离相等）。
第三步：等量代换得DG=CD 已知BD=CD， ∴ DG = CD。
第四步：用判定定理证平分线 ∵ ∠ACD=90°，∴ DC⊥AC。 ∵ DG⊥EF，DC⊥AC，且DG=CD， ∴ 点D在∠EFC的平分线上，即FD平分∠EFC。
中考规范最终答案
证明：过点D作DG⊥EF于G。 ∵ ∠ABD=90°，∴ DB⊥AB。 ∵ ED平分∠BEF，DB⊥AB，DG⊥EF， ∴ DB = DG。 又∵ BD=CD，∴ DG = CD。 ∵ ∠ACD=90°，∴ DC⊥AC。 ∵ DG⊥EF，DC⊥AC，DG=CD， ∴ FD平分∠EFC。
(2) 求证：EF=BE+CF
模块1 答案解析
通过HL证明两组直角三角形全等，将BE转化为EG，CF转化为GF，从而EF=EG+GF=BE+CF。
模块2 解析过程
审题与切入
证明一条线段等于两条线段之和，常用“截长补短”。这里作了DG⊥EF，刚好把EF分成EG和GF两段，只需证明EG=BE、GF=CF，用HL证明直角三角形全等即可。
解题思路与核心定理
直角三角形全等判定HL：斜边和一条直角边对应相等的两个直角三角形全等； 全等三角形对应边相等。
具体推导过程
第一步：证Rt△BDE ≌ Rt△GDE 在Rt△BDE和Rt△GDE中： ​ $\begin{cases} DE = DE \quad (公共边) \\ BD = GD \quad (已证) \end{cases}$ ∴ Rt△BDE ≌ Rt△GDE（HL）， ∴ BE = GE（全等三角形对应边相等）。
第二步：证Rt△CDF ≌ Rt△GDF 在Rt△CDF和Rt△GDF中： ​ $\begin{cases} DF = DF \quad (公共边) \\ CD = GD \quad (已证) \end{cases}$ ∴ Rt△CDF ≌ Rt△GDF（HL）， ∴ CF = GF（全等三角形对应边相等）。
第三步：线段和差代换 ∵ EF = GE + GF， 代入BE=GE、CF=GF得： EF = BE + CF。
中考规范最终答案
证明： 在Rt△BDE和Rt△GDE中： ​ $\begin{cases} DE=DE \\ BD=GD \end{cases}$ ∴ Rt△BDE ≌ Rt△GDE（HL），∴ BE=GE。 同理可证Rt△CDF ≌ Rt△GDF（HL），∴ CF=GF。 ∵ EF = GE + GF， ∴ EF = BE + CF。
(3) 求BE的长
模块1 答案解析
BE的长为 $\boldsymbol{2.5}$ （或 $\boldsymbol{\dfrac{5}{2}}$ ）。
模块2 解析过程
审题与切入
已有EF=BE+CF这个关系式，再找到BE与CF的另一个等量关系，联立方程组即可求解。另一个关系来自AB=AC，可通过HL证明Rt△ABD≌Rt△ACD得到。
解题思路与核心定理
HL证明直角三角形全等； 二元一次方程组求解线段长度。
具体推导过程
第一步：设未知数，列第一个方程 设BE = x，CF = y。 由(2)的结论：EF = BE + CF = 4， 即 $x + y = 4$ ①。
第二步：证AB=AC，列第二个方程 在Rt△ABD和Rt△ACD中： ​ $\begin{cases} BD = CD \\ AD = AD \quad (公共边) \end{cases}$ ∴ Rt△ABD ≌ Rt△ACD（HL）， ∴ AB = AC。
∵ AB = AE + BE = 5 + x， AC = AF + CF = 6 + y， ∴ 5 + x = 6 + y， 整理得： $x - y = 1$ ②。
第三步：解方程组 联立①②： ​ $\begin{cases} x + y = 4 \\ x - y = 1 \end{cases}$ 两式相加： $2x = 5$ ，解得 $x = 2.5$ ， 代入得 $y = 1.5$ 。 因此BE = 2.5。
中考规范最终答案
解：设BE=x，CF=y。 由(2)得： $x + y = 4$ ①。 在Rt△ABD和Rt△ACD中： ​ $\begin{cases} BD=CD \\ AD=AD \end{cases}$ ∴ Rt△ABD ≌ Rt△ACD（HL），∴ AB=AC。 ∵ AB=5+x，AC=6+y， ∴ 5+x = 6+y，即 $x - y = 1$ ②。 联立①②解得： $x=2.5$ ， $y=1.5$ 。 答：BE的长为2.5。
