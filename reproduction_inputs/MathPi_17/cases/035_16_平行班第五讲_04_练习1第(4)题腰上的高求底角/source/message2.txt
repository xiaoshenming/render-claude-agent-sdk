```python
# PROBLEM_TEXT: (1) 已知一个等腰三角形的两条边分别为 3cm 和 4cm，则这个三角形的周长为 _______. (2) 等腰三角形的一个外角为 130°，则顶角为 _______. (3) 等腰三角形一腰上的中线将它们的周长分为 6 和 12 两部分，则腰长为 _______. (4) 等腰三角形一腰上的高与另一腰的夹角为 40°，则这个等腰三角形的底角为 _______.
# FIGURE_FACTS: 等腰三角形ABC，AB=AC，BD是腰AC上的高，角ABD=40度

from manim import *
import numpy as np

class IsoscelesTriangleScene(Scene):
    def construct(self):
        # 定义顶点坐标
        A = np.array([0, 2.4, 0])
        B = np.array([-1.69, -1.225, 0])
        C = np.array([1.69, -1.225, 0])
        D = np.array([1.086, 0.07, 0])
        
        # 绘制三角形和高线
        triangle = Polygon(A, B, C, stroke_width=3, color=WHITE)
        height_line = Line(B, D, stroke_width=3, color=BLUE)
        
        # 标注字母
        label_A = MathTex("A").next_to(A, UP, buff=0.15)
        label_B = MathTex("B").next_to(B, DOWN + LEFT, buff=0.15)
        label_C = MathTex("C").next_to(C, DOWN + RIGHT, buff=0.15)
        label_D = MathTex("D").next_to(D, UP + RIGHT, buff=0.1)
        
        # 计算直角标记的顶点
        u = (A - D) / np.linalg.norm(A - D)
        v = (B - D) / np.linalg.norm(B - D)
        s = 0.2
        p1 = D + s * u
        p3 = D + s * v
        p2 = p1 + s * v
        right_angle = VMobject()
        right_angle.set_points_as_corners([p1, p2, p3])
        right_angle.set_color(BLUE)
        
        # 夹角弧线和标注
        angle_arc = Arc(radius=0.6, start_angle=25*DEGREES, angle=40*DEGREES, arc_center=B, color=YELLOW)
        label_pos = B + 0.95 * np.array([np.cos(45*DEGREES), np.sin(45*DEGREES), 0])
        label_40 = MathTex("40^\\circ", color=YELLOW).move_to(label_pos).scale(0.8)
        
        # AB 的等腰标记
        u_AB = (B - A) / np.linalg.norm(B - A)
        w_AB = np.array([-u_AB[1], u_AB[0], 0])
        m_AB = (A + B) / 2
        mark1_ab = Line(m_AB - 0.05*u_AB - 0.08*w_AB, m_AB - 0.05*u_AB + 0.08*w_AB, stroke_width=1.5, color=WHITE)
        mark2_ab = Line(m_AB + 0.05*u_AB - 0.08*w_AB, m_AB + 0.05*u_AB + 0.08*w_AB, stroke_width=1.5, color=WHITE)

        # AC 的等腰标记
        u_AC = (C - A) / np.linalg.norm(C - A)
        w_AC = np.array([-u_AC[1], u_AC[0], 0])
        m_AC = (A + C) / 2
        mark1_ac = Line(m_AC - 0.05*u_AC - 0.08*w_AC, m_AC - 0.05*u_AC + 0.08*w_AC, stroke_width=1.5, color=WHITE)
        mark2_ac = Line(m_AC + 0.05*u_AC - 0.08*w_AC, m_AC + 0.05*u_AC + 0.08*w_AC, stroke_width=1.5, color=WHITE)
        
        # 组合所有几何元素
        geometry = VGroup(
            triangle, height_line, right_angle, angle_arc, label_40,
            label_A, label_B, label_C, label_D,
            mark1_ab, mark2_ab, mark1_ac, mark2_ac
        )
        
        self.add(geometry)
```

【读题展示阶段】
展示题图并读题：等腰三角形一腰上的高与另一腰的夹角为 $40°$，求这个等腰三角形的底角。重点标出腰上的高、另一腰及它们的夹角。

【思路切入阶段】
腰上的高可能落在三角形内部，也可能落在腰的延长线上。两种图形对应锐角等腰三角形和钝角等腰三角形，需要分别利用直角三角形两锐角互余求顶角，再由两底角相等求底角。

【满分答案阶段：必须完整展示的官方解题步骤】
解：分两种情况讨论。
① 当高在三角形内部时，顶角为
$90°-40°=50°$，
所以底角为
$\dfrac{180°-50°}{2}=65°$。
② 当高在三角形外部时，顶角的邻补角为
$90°-40°=50°$，
所以顶角为 $180°-50°=130°$，底角为
$\dfrac{180°-130°}{2}=25°$。
综上，等腰三角形的底角为 $65°$ 或 $25°$。

【结论收束阶段】
高的位置不同会形成锐角、钝角两种等腰三角形，因此底角为 $65°$ 或 $25°$。

【技巧总结阶段】
腰上高涉及夹角时，先判断垂足在边上还是延长线上，分类画图后再利用互余、互补和内角和计算。
