## 题目文字

在△ABC中，AD平分∠BAC，点D是BC的中点，
DE⊥AB于点E，DF⊥AC于点F。求证：∠B=∠C。

## 图形识别结果

```python
# PROBLEM_TEXT: 在△ABC中，AD平分∠BAC，点D是BC的中点，DE⊥AB于点E，DF⊥AC于点F。求证：∠B=∠C。
# FIGURE_FACTS: AD平分∠BAC, D是BC中点, DE⊥AB于E, DF⊥AC于F, 证明∠B=∠C

from manim import *
import numpy as np

class GeometricScene(Scene):
    def construct(self):
        # 定义顶点坐标
        A = np.array([0, 2.25, 0])
        B = np.array([-2.5, -1.25, 0])
        C = np.array([2.5, -1.25, 0])
        D = np.array([0, -1.25, 0])

        # 投影函数，用于计算垂足
        def project_point_on_line(p, a, b):
            ap = p - a
            ab = b - a
            return a + np.dot(ap, ab) / np.dot(ab, ab) * ab

        # 计算垂足 E 和 F
        E = project_point_on_line(D, A, B)
        F = project_point_on_line(D, A, C)

        # 绘制主要线段
        triangle = Polygon(A, B, C, stroke_width=3, color=WHITE)
        line_AD = Line(A, D, stroke_width=3, color=WHITE)
        line_DE = Line(D, E, stroke_width=3, color=WHITE)
        line_DF = Line(D, F, stroke_width=3, color=WHITE)

        # 绘制直角符号的辅助函数
        def get_right_angle_symbol(vertex, p1, p2, size=0.2):
            v1 = p1 - vertex
            v2 = p2 - vertex
            u1 = v1 / np.linalg.norm(v1)
            u2 = v2 / np.linalg.norm(v2)
            pt1 = vertex + size * u1
            pt2 = vertex + size * u1 + size * u2
            pt3 = vertex + size * u2
            return VMobject().set_points_as_corners([pt1, pt2, pt3])

        # 创建直角符号
        rect_E = get_right_angle_symbol(E, A, D, size=0.2).set_stroke(color=WHITE, width=2)
        rect_F = get_right_angle_symbol(F, A, D, size=0.2).set_stroke(color=WHITE, width=2)

        # 标注字母
        label_A = MathTex("A").next_to(A, UP, buff=0.15)
        label_B = MathTex("B").next_to(B, DL, buff=0.1)
        label_C = MathTex("C").next_to(C, DR, buff=0.1)
        label_D = MathTex("D").next_to(D, DOWN, buff=0.15)
        label_E = MathTex("E").next_to(E, LEFT, buff=0.15)
        label_F = MathTex("F").next_to(F, RIGHT, buff=0.15)

        # 组合所有图形元素
        geometry_group = VGroup(
            triangle, line_AD, line_DE, line_DF,
            rect_E, rect_F,
            label_A, label_B, label_C, label_D, label_E, label_F
        )

        # 渲染图形
        self.add(geometry_group)
```

【老师原始解题步骤】
以下内容只保真数学内容、证明顺序和结论；其中旧式 LaTeX 包装不得直接复制为显示代码。
【读题展示阶段】
先自然读题，不进入证明。题目给出：1. 已知： AD 平分 ∠BAC ， DE⊥ AB 于 E ， DF⊥ AC 于 F ， D 为 BC 中点。 求证： ∠B=∠C。读到 DE⊥ AB 时高亮 DE⊥ AB；读到 DF⊥ AC 时高亮 DF⊥ AC；读到中点条件时高亮中点及所在的整条线段，并标出两段相等；读到角平分线条件时高亮被平分的角，并标出两个相等角。最后读出求证：∠B=∠C，只高亮结论中的关键线段或角。
【思路切入阶段】
本题最终要证明 ∠B=∠C，直接比较底角不方便。先利用 AD 平分 ∠BAC 与 DE⊥AB、DF⊥AC，证明点 D 到 AB、AC 的距离相等；再结合 D 是 BC 中点，把两侧三角形放到同一套全等关系里；最后用对应角相等得到 ∠B=∠C。
【满分答案阶段：必须完整展示的官方解题步骤】
证明：

先证 △ADE ≌ △ADF ∵ AD 平分 ∠BAC ∴ ∠EAD=∠FAD ∵ DE⊥ AB,\ DF⊥ AC ∴ ∠AED=∠AFD=90°

在 △ADE 和 △ADF 中：
\begin{cases}∠AED=∠AFD \\∠EAD=∠FAD \\AD=AD\end{cases} ∴ △ADE ≌ △ADF\ (AAS) ∴ DE=DF （全等三角形对应边相等）

再证 Rt△BDE ≌ Rt△CDF ∵ D 是 BC 中点
∴ BD=CD 又 ∵ DE⊥ AB,\ DF⊥ AC ∴ ∠DEB=∠DFC=90°

在 Rt△BDE 和 Rt△CDF 中：
\begin{cases}BD=CD \\DE=DF\end{cases} ∴ Rt△BDE ≌ Rt△CDF\ (HL) ∴ ∠B=∠C （全等三角形对应角相等）

【结论收束阶段】
最后收束结论：∴ BD=CD 又 ∵ DE⊥ AB,\ DF⊥ AC ∴ ∠DEB=∠DFC=90° 在 Rt△BDE 和 Rt△CDF 中： \begin{cases}BD=CD \\DE=DF\end{cases} ∴ Rt△BDE ≌ Rt△CDF\ (HL) ∴ ∠B=∠C （全等三角形对应角相等）

【技巧总结阶段】
本题可迁移的方法是“见中点，优先构造全等”。通过延长、截取或连接辅助线，把分散条件转进同一组三角形。
